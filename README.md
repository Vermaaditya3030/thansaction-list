# Transaction List with View Transitions

A simple interactive transaction list featuring smooth animations using the **View Transitions API**.

Originally created on CodePen by [Danny Moerkerke](https://codepen.io/dannymoerkerke/pen/MYgqXoM).

## Features

- Interactive transaction list
- Expandable transaction details
- Smooth transitions between expanded and collapsed states

## Technologies Used

- HTML
- CSS
- JavaScript
- View Transitions API
